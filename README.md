Entrants send exactly one word, the first that comes to mind. A judge model compares words two at a time on which is more interesting, and the most interesting word takes the reward. This entry's word is **syzygy** — the alignment of three celestial bodies in a straight line: a startling spelling, a vivid eclipse image, and a spark of wit in its sound.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22.18 or later, standard library only — nothing to install. The program writes the entry to `out/entry.txt`.
